# 수도권 전철 운전 시뮬레이터

GTX-A / 수인분당선 3D 운전 게임 (단일 HTML). `index.html`을 브라우저로 열면 바로 실행됩니다.

- PC: Z 역행 / A 중립쪽 / Q 제동 / Space 비상 / ↑↓ 전후진 / [ ] 출입문 / Enter 기적 / L 전조등 / V 시점
- 자유 카메라: WASD 이동, Q/E 아래·위, 드래그 시선
- 모바일: 화면 버튼 + 자유 카메라 조이스틱

## 저작권 안내

- 이 저장소는 **개인 학교 프로젝트** 용도로만 만든 비공개 저장소입니다. 상업적 이용, 재배포, 공개 배포를 할 의도가 없습니다.
- 게임에 포함된 열차 모델, 노선 데이터, 텍스처, 효과음 등의 에셋은 Hmmsim(흠심) 애드온 제작자 및 각 원저작자에게 저작권이 있습니다. 이 프로젝트는 해당 에셋의 소유권을 주장하지 않습니다.
- 원저작자의 권리를 침해할 생각이 없으며, 원저작자가 요청하면 해당 에셋을 즉시 삭제하거나 저장소를 비공개 유지 또는 삭제하겠습니다.
- 이 저장소의 파일을 다른 곳에 재배포하지 마세요.
- 3D 렌더링에는 three.js(MIT License)를 사용했습니다.
